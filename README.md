# NewDay — Личный планировщик

Веб-приложение для планирования дня, отслеживания привычек, задач, веса и прогресса.

- **Сайт**: https://newday.appswire.ru
- **Стек**: Node.js · Express · SQLite · Vanilla JS
- **Развёртывание**: один Docker-контейнер

---

## Быстрый старт (локально)

### Требования
- Node.js 18+

### Установка
```bash
npm install
cp .env.example .env
# Отредактируйте .env — смените SESSION_SECRET
```

### Запуск
```bash
npm start
# или для разработки:
npm run dev
```

Откройте в браузере: **http://localhost:3000**

---

## Запуск через Docker

```bash
cp .env.example .env
# Обязательно смените SESSION_SECRET в .env

docker compose up -d
```

Приложение будет доступно на **http://localhost:3000**.

База данных хранится в `./data/newday.db` (volume примонтирован в контейнер).

## Развёртывание через Coolify

1. Загрузите проект в Git-репозиторий.
2. В Coolify создайте новый сервис → **Docker Compose**.
3. Укажите URL репозитория.
4. Coolify автоматически найдёт `docker-compose.yaml` в корне.
5. Добавьте переменные окружения из `.env.example` в настройках Coolify:
   - `SESSION_SECRET` — длинная случайная строка
   - `DB_PATH` — `/app/data/newday.db`
   - `NODE_ENV` — `production`
6. Настройте домен `newday.appswire.ru` → порт `3000`.
7. Volume `./data:/app/data` обеспечивает сохранение базы данных.

> **Важно**: Coolify использует встроенный прокси (Traefik/Caddy), который добавит HTTPS автоматически.

## Использование

### Экран дня

Слева от расписания идёт вертикальный рельс, по которому движется настоящее:
текущая строка подсвечена и показывает, сколько до её конца, прошедшие приглушены.
День переключается стрелками в шапке, свайпом на телефоне или кнопкой «Сегодня».
Отдельного действия «создать день» нет — день появляется, как только в него что-то записали.

- **Расписание** — два вида, переключатель `☰ / ▦` в заголовке секции. Список компактнее
  и печатается, таймлайн показывает длительность и дыры в дне. На бумагу всегда идёт список.
- **Сдвиг времени** — кнопка `⏱` на строке: `+15`, `+30`, `−15` или произвольно,
  с галочкой «и все следующие». Это сценарий «задержался на обеде».
- **Напоминания** — иконка на строке переключает `тихо → уведомление → будильник`.
  Сами уведомления появятся на следующем этапе; сейчас флаг сохраняется.
- **Задачи** — три вкладки: работа, дом, питание. Режим питания (чек-лист или
  приёмы пищи по времени) выбирается в настройках, данные при переключении не теряются.
- **Повторы** — правило живёт отдельно от дня. Изменение или удаление одного дня
  не ломает серию; серию можно завершить с любой даты, не трогая прошлое.

### Привычки

Создание в один шаг: эмодзи, название, пресет. Пресеты разворачиваются в три
независимые настройки, которые можно задать и по отдельности:

| Ось | Значения |
|---|---|
| Цель | бессрочно · челлендж на N дней |
| При срыве | начинать заново · копить дальше |
| Что отмечаю | сделал · удержался (для «бросаю») |

Плюс дни недели, количество в день и «заморозки» — пропуски, которые не портят серию
и не входят в процент. Удаление по умолчанию отправляет в архив: история отметок остаётся.

### Печать

Кнопка `🖨` открывает диалог: что печатать и что делать, если день не помещается
на лист — уменьшить шрифт или разложить на две страницы. Лист чёрно-белый,
галочки печатаются рамкой, справа от каждой строки идёт колонка «факт»,
внизу — линейки для рукописных заметок.

### Темы

Светлая, тёмная и системная. Выбор хранится локально (чтобы страница не мигала
при загрузке) и на сервере (чтобы совпадал между устройствами).

### Вход с телефона

Настройки → «Показать код для входа» → отсканировать QR приложением.
Код одноразовый и живёт две минуты; рядом есть восьмизначный код на случай,
если камера не сработала. Подключённые устройства видны списком и отзываются одной кнопкой.

## Сборка Android APK (через Capacitor)

Capacitor создаёт Android-приложение, которое открывает сайт `newday.appswire.ru` внутри WebView.

**Требования**: Android Studio, JDK 17+

### Шаги сборки

```bash
# 1. Установить все зависимости (включая devDependencies)
npm install

# 2. Добавить Android-платформу (первый раз)
npx cap add android

# 3. Синхронизировать (после любых изменений)
npx cap sync

# 4. Открыть проект в Android Studio
npx cap open android
```

В Android Studio:
- **Build → Generate Signed Bundle / APK → APK**
- Выберите или создайте keystore
- Build Variant: **release**
- Соберите APK

### Куда положить APK

После сборки скопируйте файл APK:
```
app/build/outputs/apk/release/app-release.apk
→ public/downloads/NewDay.apk
```

После этого кнопка «📱 Android» → «Скачать NewDay.apk» на сайте заработает.

### Как заменить иконку в Android-приложении

После `npx cap add android`:
- Откройте Android Studio
- **Tools → Resource Manager → + → Image Asset**
- Выберите свой файл иконки
- Android Studio сгенерирует все размеры автоматически

### Примечания

- APK-приложение требует доступа к интернету (открывает сайт через WebView).
- Для установки APK на Android нужно разрешить «Установку из неизвестных источников».
- **Альтернатива без сборки**: установить сайт как PWA через Chrome → «Добавить на главный экран».

## API

Полная спецификация — **`/api/v1/openapi.json`**, человекочитаемая страница — **`/api/docs`**.

Аутентификация — cookie-сессия (веб) либо персональный токен: `Authorization: Bearer nd_…`.
Токен создаётся в настройках и показывается один раз; есть режимы «только чтение» и «чтение и запись».

```bash
curl -H "Authorization: Bearer nd_xxxxxxxx_..."      https://newday.appswire.ru/api/v1/days/2026-08-03/full
```

Заполнить день целиком — например, из бота или LLM. Нужен заголовок `If-Match`
с текущим `rev` дня (для нового дня это `0`):

```bash
curl -X PUT -H "Authorization: Bearer nd_..."      -H "Content-Type: application/json" -H 'If-Match: "0"'      -d '{"title":"План","schedule":[{"time":"06:00-06:30","title":"Подъём","alarmMode":"alarm"}]}'      https://newday.appswire.ru/api/v1/days/2026-08-04/full
```

Основные группы: `/auth/*`, `/days/*` (плюс вложенные `schedule`, `tasks`, `meals`, `sport`),
`/habits/*`, `/stats`, `/settings`, `/tokens`, `/devices`, `/export`, `/import`.

Старые пути `/api/auth/*`, `/api/days/*`, `/api/habits/*` работают как алиасы
и будут удалены после переписывания фронтенда.

### Модель данных

День больше не хранится одним JSON-блобом: расписание, задачи, питание и спорт лежат
в отдельных таблицах, и каждый эндпоинт правит одну строку. У дня есть счётчик версий
`rev` — он нужен только двум операциям, переписывающим день целиком
(`PUT /days/{date}/full` и `PATCH /days/{date}`). Правки отдельных строк между собой
не конфликтуют, поэтому телефон и компьютер могут работать с одним днём одновременно.

Даты — строки `YYYY-MM-DD` в таймзоне пользователя (`Europe/Moscow` по умолчанию).
Время — целые минуты от полуночи.

## .env переменные

| Переменная     | По умолчанию            | Описание                                             |
|----------------|-------------------------|------------------------------------------------------|
| PORT           | 3000                    | Порт сервера                                          |
| SESSION_SECRET | —                       | Секрет сессии — **обязательно смените**               |
| DB_PATH        | ./data/newday.db        | Путь к базе данных                                    |
| NODE_ENV       | development             | В `production` cookie помечается `Secure`             |
| APP_URL        | http://localhost:3000   | Внешний адрес, попадает в ссылки из писем             |
| TRUST_PROXY    | 1                       | `0`, если приложение не за обратным прокси            |
| SMTP_HOST      | —                       | Пусто → подтверждение почты отключено                 |
| SMTP_PORT      | 465                     | Порт SMTP                                             |
| SMTP_SECURE    | 1                       | `0` для STARTTLS                                      |
| SMTP_USER      | —                       | Логин SMTP                                            |
| SMTP_PASS      | —                       | Пароль SMTP                                           |
| SMTP_FROM      | = SMTP_USER             | Адрес отправителя                                     |

Без `SMTP_HOST` приложение поднимается и работает, просто регистрация не требует
подтверждения адреса, а восстановление пароля недоступно.

## Бэкапы

Снимок базы делается автоматически перед применением миграций и раз в сутки,
в `<каталог базы>/backups/`, хранятся последние 14 копий. Выгрузка своих данных
в JSON — `GET /api/v1/export`, загрузка обратно — `POST /api/v1/import`.
