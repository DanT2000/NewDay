# Исходники знака

Здесь лежат большие версии логотипа, из которых собираются все остальные
иконки. В `public/` их нет нарочно: они никуда не подключаются, но попадали и в
кеш браузера, и внутрь APK — два мегабайта, которые никто никогда не открывает.

Пересобрать иконки:

```bash
# всё сразу: веб, PWA и Android
python tools/make-icons.py brand/logo-dark-1024.png

# только иконка запуска Android — она светлая, чтобы не выглядеть дырой
# среди чужих значков на рабочем столе
python tools/make-icons.py brand/logo-light-1024.png --android-only
```

`logo-256`, `logo-dark-64` и `logo-light-64` в `public/icons/` — рабочие: первый
стоит на страницах входа, вторые два переключаются вместе с темой.
