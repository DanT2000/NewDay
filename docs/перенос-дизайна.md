# Перенос макета Claude Design в приложение

Источник: проект «NewDay app design», файлы `NewDay.dc.html` и
`NewDay — описание функционала.md`. Документ отвечает на один вопрос:
что из макета уже есть, что нужно построить и в каком порядке.

Логика приложения — в [логика.md](логика.md); здесь только перенос.

---

## Что макет меняет по существу

Это не перекраска. Меняется структура приложения и появляются четыре
сущности, которых в базе нет вовсе.

| Из макета | Сейчас | Объём работы |
|---|---|---|
| 5 вкладок, «Сейчас» в центре | 5 ссылок, экран дня главный | новый экран + каркас |
| Экран «Сейчас» | — | **новый** |
| Расписание без галочек | галочка в строке | убрать, отметки живут в «Делах» |
| Начало / длится / конец тремя плитками | поле времени и длительности | переделать редактор |
| Пересечение: сдвинуть · сократить · внахлёст | только каскадный сдвиг | два новых варианта |
| Вложенный блок склеенной карточкой | — | новое |
| Несколько предупреждений на строку | одно `remind_before_min` | **миграция + API** |
| Будильник настраивается у строки | глобально в настройках | **миграция + перенос настроек** |
| Задачи: работа · дом · личное · покупки | работа · дом | **миграция** |
| Питание: план текстом, цель ккал, три режима времени | чек-лист или время | **миграция + API** |
| Напоминания как сущность с повторами | нет | **новая сущность** |
| Заметки как сущность, с датой или без | поле в дне | **новая сущность** |
| Задача будильника: код и шаги | пример, код, иконки | **нативная работа** |
| Звуки: пресеты, «Случайный» | системный звук будильника | нативная работа |
| Общее расписание — шаблон дня | нет | новая сущность |
| Помощник (ИИ) | нет | новое, отдельно |
| Цвет приложения: 4 акцента | цвет только там, где данные | смена системы цвета |

Пять миграций, новый экран, переписанный каркас, добавления в нативный
будильник и отдельный разговор про ИИ. Одним куском это не сдаётся.

## Что уже сходится с макетом

Сделано раньше и совпало:

- **расписание вне прогресса дня** — макет тоже держит отметки в «Делах»;
- **неделя точками у привычки** и полоса челленджа;
- **шторки** — модалка уже превращается в нижний лист на узком экране;
- **ввод времени без клавиатуры** — сетка часов и чипы минут;
- **два режима времени у питания** (чек-лист и по времени) — макет добавляет
  к ним третий, «временное окно»;
- будильник с задачами, тихое начало, проверка разрешений.

## Порядок

Каждый этап сам по себе имеет смысл и уезжает в прод.

### 1. Основание — *сделано*

Токены Nocturne (тёмная и светлая), четыре акцента, вшитые Inter и Phosphor,
каркас из пяти вкладок, типографика макета.

Важное решение: **шрифт и иконки вшиты в репозиторий**, а не берутся с CDN.
Веб-часть работает внутри APK без интернета — ссылка на Google Fonts и unpkg
там молча не сработала бы, и приложение поехало бы системным шрифтом без
иконок. `tools/vendor-font.mjs` и `tools/vendor-icons.mjs` собирают ровно то,
что нужно: два файла шрифта (65 КБ, кириллица и латиница) и 63 иконки
готовыми путями SVG вместо девяти тысяч глифов шрифта иконок.

### 2. Экран «Сейчас» и расписание как план

Карточка текущего блока с остатком времени, «было / дальше», три плитки
прогресса. Расписание теряет галочки. Редактор строки: три плитки времени,
пересечение с тремя вариантами, вложенные блоки склеенной карточкой.

### 3. «Дела»

Категории задач (миграция), спорт в новом виде, питание с планом дня и целью
по калориям, блок напоминаний дня, блок заметок дня.

### 4. Напоминания и заметки как сущности

Две миграции, API, участие в планировщике уведомлений, экран «Заметки»
с фильтрами и шторка заметки.

### 5. Будильник у строки

Перенос настроек будильника из общих в строку расписания: способ выключения,
тип задачи, пропуск в первую минуту, проверка пробуждения. Новые типы задач —
код (штрих или QR) и шаги по акселерометру. Звуки: пресеты и «Случайный».

### 6. Общее расписание, печать и данные шторками, вход сегментом

### 7. Помощник (ИИ) — отдельно

На машине есть LM Studio с OpenAI-совместимым API (порт 1234, модели
gemma 12B и llama 3.2 1B). Разбор свободной речи в структуру делается через
такой же эндпоинт, адрес и модель — в переменных окружения, чтобы у себя
можно было поставить что угодно. Проверять на живой модели пока отложено.

## Чего в макете нет, а в приложении есть

Это не забыто, а требует решения:

- **экран «Итоги»** с графиками за 30 дней — в новой навигации его нет.
  Пока оставлен доступным из настроек, из нижних вкладок убран;
- **скачивание APK со страницы** — макет говорит «скачивания APK нет»,
  только привязка устройств. Сама раздача на сервере остаётся: без неё
  неоткуда взять первую установку и не работает автообновление;
- **печать на A4** — в макете печать есть, но как шторка с выбором
  «день / неделя / месяц»; текущий диалог печатает только день.
