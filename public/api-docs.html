Быстрый старт

Создайте токен в настройках приложения — он показывается один раз. Дальше:

curl -H "Authorization: Bearer nd_xxxxxxxx_…" \
     https://newday.appswire.ru/api/v1/days/2026-08-03/full

Заполнить день целиком (нужен If-Match с текущим rev):

curl -X PUT -H "Authorization: Bearer nd_…" \
     -H "Content-Type: application/json" -H 'If-Match: "0"' \
     -d '{"title":"План","schedule":[{"time":"06:00-06:30","title":"Подъём","alarmMode":"alarm"}]}' \
     https://newday.appswire.ru/api/v1/days/2026-08-04/full
