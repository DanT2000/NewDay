# Иконки приложения NewDay

Положите сюда иконки приложения:

- `icon-192.png` — 192×192 px (PNG, RGBA)
- `icon-512.png` — 512×512 px (PNG, RGBA)

Иконки используются в:
- PWA manifest (установка на Android/iOS/Desktop)
- Android-приложении через Capacitor

## Как создать иконку

1. Создайте квадратное изображение 512×512 px (логотип на светлом или прозрачном фоне).
2. Сохраните как `icon-512.png`.
3. Уменьшьте до 192×192 px и сохраните как `icon-192.png`.
