NewDay для Android

Вариант 1 — Добавить на экран (PWA)

Самый простой способ. Работает прямо в браузере.

  1. Откройте newday.appswire.ru в браузере Chrome на Android.
  2. Нажмите меню (⋮) → «Добавить на главный экран».
  3. Нажмите «Установить».
  4. NewDay появится на главном экране как приложение.

Вариант 2 — Скачать APK

Полноценное Android-приложение (требует разрешить установку из неизвестных источников).

Примечание: APK-приложение открывает сайт newday.appswire.ru внутри WebView. Для работы нужен доступ к интернету и к серверу.
