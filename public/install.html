NewDay на телефоне

Два способа, между ними есть важная разница

приложение · есть будильник

Полноценное приложение: работает без интернета и умеет будильник — звонит в беззвучном режиме и при «Не беспокоить», поднимает экран поверх блокировки и требует решить задачу, чтобы выключиться.

Скачать APK

Дальше приложение обновляется само: при запуске оно спрашивает сервер, нет ли версии новее, и предлагает обновиться. Отложить можно — вопрос вернётся на следующий день, а проверить вручную получится в Настройках в любой момент.

После установки при первом запуске укажите адрес сервера — по умолчанию подставлен этот сайт. Затем зайдите в Настройки → Будильник и пройдите проверку разрешений: без них Android не даст будильнику сработать, и приложение об этом честно предупредит.

Android не даёт установить файл

Разрешите установку из неизвестных источников для браузера или файлового менеджера: Настройки → Приложения → ваш браузер → Установка неизвестных приложений. Это нормальное поведение для приложений, которые ставятся не из Google Play.

ярлык на экране · без будильника

Сайт можно поставить на главный экран как обычное приложение — ничего скачивать не нужно. Уведомления работают, а вот будильника здесь нет: браузеру не разрешено включать экран, звучать в беззвучном режиме и держать звук в фоне.

Chrome на Android: меню ⋮ → Добавить на главный экран.

Открыть в браузере
собрать самому

Проект открыт, APK собирается из исходников: 

git clone https://github.com/DanT2000/NewDay
cd NewDay && npm install
npx cap sync android
cd android && ./gradlew assembleDebug

Готовый файл — в android/app/build/outputs/apk/debug/. Для раздачи другим людям нужна релизная сборка со своим ключом подписи, как это делать — в README.
