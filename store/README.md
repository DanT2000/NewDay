# ru.appswire.newday — материалы для магазинов

Версия **1.0.8**, versionCode **10008**.

Всё готовое разложено по папкам — брать оттуда и загружать:

| Куда | Папка | Что внутри |
|---|---|---|
| Google Play | [google-play/](google-play/) | AAB, значок, изображение 1024×500, 8 скриншотов, тексты |
| RuStore | [rustore/](rustore/) | APK, значок, 10 скриншотов, тексты |

В каждой папке лежит `ЧТО-ЗАГРУЖАТЬ.md` — что именно этот магазин просит и в каком порядке ставить кадры.

## Что где ещё

- [STORE-LISTING.md](../STORE-LISTING.md) — ответы на все вопросы консоли: категории, возрастной рейтинг, форма о данных, обоснования разрешений, целевая аудитория.
- [PUBLISHING.md](../PUBLISHING.md) — сборка, подпись, чем отличаются сборки для двух магазинов и проверки перед загрузкой.
- `screens/` — исходные десять кадров, из них и собираются папки магазинов.

## Пересобрать

```bash
node tools/store-shots.mjs         # кадры 01–08, веб-часть
node tools/store-alarm-shots.mjs   # кадры 09–10, будильник на эмуляторе
node tools/feature-graphic.mjs     # изображение 1024×500
node tools/store-assets-check.mjs  # размеры, пропорции и вес
node tools/store-kit.mjs           # разложить по папкам магазинов
```

Сборки (`.aab` и `.apk`) в папках лежат, но в git не хранятся: это артефакты, они пересобираются командами из PUBLISHING.md.
